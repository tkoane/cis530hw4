# 金融数据自动提取工具 - 使用说明

## 这个工具能做什么？

你把**群聊截图**或**文字记录**放到 `input` 文件夹里，运行一条命令，工具就会自动：
1. 识别图片中的文字（OCR）
2. 提取金融相关数据（营收、利润、股价等）
3. 生成/更新一个 Excel 表格到 `output` 文件夹

---

## 第一步：安装 Python（如果还没有的话）

### Windows 用户
1. 打开 https://www.python.org/downloads/
2. 下载最新版 Python，安装时 **勾选 "Add Python to PATH"**

### Mac 用户
打开"终端"（在启动台搜索"终端"），输入：
```
brew install python3
```

---

## 第二步：安装依赖

打开命令行（Windows 搜索 "cmd"，Mac 打开"终端"），输入：

```bash
cd financial_tool
pip install -r requirements.txt
```

### 如果需要处理图片（群聊截图）

还需要安装 Tesseract OCR 引擎：

**Windows:**
1. 下载安装包: https://github.com/UB-Mannheim/tesseract/wiki
2. 安装时勾选中文语言包 (Chinese Simplified)
3. 安装后把 Tesseract 路径加到系统环境变量

**Mac:**
```bash
brew install tesseract
brew install tesseract-lang
```

> 如果你只用文字文件（不用图片），可以跳过这一步。

---

## 第三步：配置（可选）

打开 `config.json` 文件，可以修改：

```json
{
  "company_name": "改成你关注的公司名",
  "excel_filename": "改成你想要的Excel文件名.xlsx",
  "keywords": ["在这里添加你关心的金融关键词"]
}
```

---

## 第四步：使用

### 基本用法

1. **把文件放入 `input` 文件夹**
   - 支持的图片格式：`.png`, `.jpg`, `.jpeg`, `.bmp`, `.tiff`, `.webp`
   - 支持的文字格式：`.txt`, `.csv`

2. **运行命令**
   ```bash
   python process_data.py
   ```

3. **查看结果**
   - 打开 `output/financial_data.xlsx`

### 自动监控模式

如果你想让工具**一直运行**，自动检测新文件：

```bash
python process_data.py --watch
```

这样每当你往 `input` 文件夹放新文件，Excel 就会自动更新。

按 `Ctrl+C` 停止监控。

### 重新处理所有文件

```bash
python process_data.py --reset
```

## 文件夹结构

```
financial_tool/
├── input/              ← 把截图和文字文件放这里
├── output/             ← Excel 输出在这里
├── config.json         ← 配置文件（可自定义关键词等）
├── process_data.py     ← 主程序（不需要修改）
├── requirements.txt    ← Python 依赖列表
└── 使用说明.md          ← 本文件
```

---

## 文字文件格式建议

为了让工具更好地识别数据，建议文字文件这样写：

```
2024-03-15
营收: 50.2亿元
净利润: 8.5亿元，同比增长 15.3%
毛利率: 35.2%
股价: 128.50元，涨幅 2.3%
成交量: 1500万股
```

每行写一个指标，包含关键词和数值即可。

## 常见问题

**Q: 图片识别不准确怎么办？**
A: 确保图片清晰，分辨率足够。如果识别效果不好，可以手动把关键数据写成 .txt 文件。

**Q: 想添加新的关键词？**
A: 编辑 `config.json` 文件，在 `keywords` 列表中添加。

**Q: 处理了错误的文件怎么办？**
A: 删除 `output/financial_data.xlsx`，删除 `.processed_files.json`，重新运行即可。

**Q: Excel 太大了怎么办？**
A: 可以把旧的 Excel 备份后删除，工具会创建新的。
