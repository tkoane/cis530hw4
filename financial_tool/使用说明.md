# 金融高频数据自动化整理工具

## 这个工具能做什么？

把你从群里收到的**图片截图**和**文字信息**自动整理成一份**Excel表格**。

每次有新数据时，只需把文件丢进文件夹，运行一下就能得到更新后的Excel。

---

## 快速开始（3步搞定）

### 第1步：安装 Python 环境

如果你的电脑还没有 Python，请下载安装：
- Windows: 去 https://www.python.org/downloads/ 下载，安装时**勾选 "Add Python to PATH"**
- Mac: 打开终端输入 `brew install python3`

### 第2步：安装依赖

打开命令行（Windows 按 Win+R 输入 cmd，Mac 打开终端），进入工具所在文件夹：

```bash
cd financial_tool
pip install -r requirements.txt
```

**如果需要处理图片**（OCR识别），还需要安装 Tesseract-OCR：
- Windows: 下载安装 https://github.com/UB-Mannheim/tesseract/wiki
- Mac: `brew install tesseract tesseract-lang`

### 第3步：使用

1. 把图片或文字文件放入 `input/` 文件夹
2. 运行：
```bash
python process_data.py
```
3. 去 `output/` 文件夹打开 Excel 即可！

---

## 两种使用模式

### 模式一：手动运行（推荐新手）

每次有新数据时：
1. 把文件放入 `input/` 文件夹
2. 双击 `一键运行.bat`（Windows）或运行 `python process_data.py`
3. 打开 `output/最新数据.xlsx` 查看结果

### 模式二：自动监控

运行后会持续监控 `input/` 文件夹，有新文件自动处理：
```bash
python watch_and_update.py
```
按 `Ctrl+C` 停止。

## 文件夹结构

```
financial_tool/
├── input/          ← 把图片和文字文件放这里
├── output/         ← 生成的 Excel 在这里
│   └── 最新数据.xlsx
├── config.json     ← 配置文件（可自定义提取规则）
├── process_data.py ← 主程序
├── watch_and_update.py  ← 实时监控程序
├── 一键运行.bat    ← Windows 双击运行
└── 使用说明.md     ← 本文件
```

## 常见问题

**Q: 图片识别不准怎么办？**
A: 图片 OCR 对清晰度要求较高。建议：
- 使用高清截图
- 文字区域尽量清晰
- 识别结果会保留在"原始内容"列，方便人工核对

**Q: 同一个文件会重复处理吗？**
A: 不会。工具会记住已处理的文件，只有新文件或被修改的文件才会重新处理。如需全部重新处理，删除 `.processed_files.json` 即可。

**Q: Excel 打开是乱码？**
A: 确保用 Excel（而不是记事本）打开 .xlsx 文件。如果是 CSV 文件，打开时选择 UTF-8 编码。
